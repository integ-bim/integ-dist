# integ-dist

Репозиторий дистрибуции плагинов ИНТЕГ для Autodesk Revit.

**Страница загрузки:** https://integ-bim.github.io/integ-dist/

## Что здесь лежит

- `index.html` — страница установки для пользователей (GitHub Pages);
- релизы с тремя файлами каждый:
  - `INTEG-<версия>-SingleUser.msi` — установщик,
  - `INTEG-Setup.msi` — та же копия под постоянным именем, на неё ведёт кнопка «Скачать»,
  - `latest.json` — манифест обновления, его читает плагин.

## Чего здесь нет

Исходного кода. Он в приватном репозитории `integ-bim/integ-revit`, там же
ведётся разработка и оттуда автоматически публикуются релизы.

Репозиторий публичный по одной причине: страница установки должна открываться
без авторизации, а плагин — проверять обновления без токена на машине
пользователя. Токен, разложенный по сорока компьютерам, отозвать невозможно.

## Правки

Руками здесь меняется только `index.html`. Файлы релизов загружает
GitHub Actions из `integ-revit` при пуше тега `v*` — вручную их выкладывать
не нужно и не следует.
